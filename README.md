# Informacioni sistem uprave sajma knjiga

Projekat iz predmeta **Osnovi informacionih sistema i softverskog inženjerstva** (2025/2026).

Desktop aplikacija za referenta sajma knjiga, pisana u jeziku C# (.NET 8).

## Struktura rešenja

| Projekat | Opis |
|---|---|
| `Core` | Zajednički sloj: modeli, serijalizacija, DAO sloj, servisi (poslovna logika) |
| `ConsoleClient` | Konzolna aplikacija (CLI) koja koristi `Core` |
